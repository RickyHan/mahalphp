          info
          매핑 규칙

          건물 하나에 채팅방 하나를 연결합니다. 이름의 별(★)·공백·'입주민방' 같은 말은 빼고 비교하며, 비슷한 후보가 둘 이상이면(예: 101동·102동) 자동으로 연결하지 않습니다. 채팅방이 더 모이면 다시 수집하기를 누르십시오. 직접 연결·해제한 건물은 자동 매핑이 바꾸지 않습니다. 목록에 없는 별 하나(★)로 시작하는 방은 '목록 외 채팅방'으로 보이며, '건물 지정'으로 목록의 건물에 붙일 수 있습니다.

              민원 자동 분류 (Gemini)

              같은 문제로 묶는 기준

              같은 방 · 같은 사람 · 같은 분류의 민원이 분 안에 다시 오면 같은 문제로 묶습니다.

              같은 문제의 반복 민원에는 접수 안내와 업체 처리 요청을 다시 보내지 않습니다. 시간을 줄이면 더 자주 새 민원으로 처리되어 안내·요청이 더 많이 나갑니다. (1~240분, 기본 15분 · 민원 대시보드·통계의 묶음에도 같은 기준 적용)

              민원 접수 안내

              {분류} {요약} {보낸사람} {방} 을 넣을 수 있습니다. 새 문제의 첫 민원에만, 수신 30분 이내일 때, 휴대폰 앱이 카톡 '답장'으로 보냅니다.
